Each has `kind: presentation-support`, an actual cached source `witness`, the sampled floor `position` below it, measured `clearance`, its own supported-center departure direction, and the existing near-ground band/cosmetic exterior roots. Eligibility starts only after that piece's existing .18/.13/.075 s strike and while fully released. Front/left retain .18 m and rear .10 m witness margins. Clearance describes that cached witness, not identical clearance at every uncached source vertex, and not authoritative collision.

Both aliases clear at birth/reset/recovery; objects and the array are reused. The gate retains at most eight racer identities and a three-bit mask per authoritative crash/birth frame. GameApp only iterates contacts inside its existing unpaused block; it passes the same racer/crash identity to all parts.

Each part's direction differentiates its supported world center, using its own strike path, cached pivot, current grade and base linear/angular motion. The existing front catch and late COM-preserving adapter remain unchanged; derivative samples issue no terrain queries. Resting zero-speed fallback uses the respective part's own departure path.

## Honest extent and capacity contracts

A rolling front can have a tiny real band: at .130001 s hero half-length is .1379658 m; at .65 s rival half-length is .00283152 m. An actual front exterior root can be 5.586–6.820 m along from that band center. The old `halfLength >= 1` / `abs(edgeAlong) <= halfLength + 4` admitted rear-only assumptions would reject these roots. New per-part calls share one gate/emitter validator: positive measured half-length >= .000001 m and <=12 m, half-width 0–6 m, normalized horizontal axis, cosmetic roots <=12 m axially and <=6 m laterally/vertically from band center. No reported band is inflated. Malformed per-part calls fail closed; context-free/legacy point/fan behavior stays unchanged.

Roots are **cached source exterior extrema**, not guaranteed global extrema of all source vertices in every orientation. They remain exact real source vertices' XZ projected onto their own cached ground samples. At front age .65, the initial exact-global-extremum assertion failed by .0407680138 m for both variants. That failure is preserved. The replacement assertion requires exact independently transformed cache extrema and exact source membership, then separately derives lateral/axial cache coverage from all actual source vertices. The tests retain full-source no-burial and near-ground-band measurements; they do not use a tolerance fitted to this one failure.

Production now allocates two existing porous billow parents per part, each at an actual copied exterior root, with two cards per parent. Six parents / 12 cards per wreck, 48 parents / 96 cards globally; same one contact mesh and nine effect owners/draw budget. Geometry, materials, alpha/depth/shader behavior and rupture flame are unchanged. One left/front cue allocates 3 grit entries; rear 4: total exactly 3 casing fragments plus 7 clods per wreck, still globally capped at 64. Legacy context calls retain their five-parent/ten-grit behavior.

Nine existing terrain probes per active parent mean 54 per changing-age wreck and 432 at the full eight-wreck pool. Held FX clock (including camera-yaw changes) issues zero queries. Owner/sequence changes, overwrite, missing rupture/recovery, reset and 1.65 s expiry release all matching cloud callbacks. Camera orientation can change independently while simulation age is held. No native/FPS/visual acceptance is claimed from these CPU checks.
