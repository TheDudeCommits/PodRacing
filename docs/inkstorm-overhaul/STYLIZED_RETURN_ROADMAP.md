The owner withdrew the photorealistic direction and requested the visuals currently on Production, keeping the latest sky. Vercel metadata resolves that baseline to **V36 / a4bb70d104c997667d4e42d29c02831af2cbd788**, READY Production at the canonical game URL. ## Scope of this revision

- Restored Production terrain, physical height field, scenery placement and original GLBs, stylized materials, cel outlines/contact post-processing, shadows, dust/wakes/exhaust/weapon effects, menu theme, HUD and pod preview presentation.
- Kept the approved Kloppenheim dusk sky: the same 4K HDR bytes, projection, sun placement, exposure and grade. It now owns a sky-only loader; no photographic ground/rock maps or vehicle-material replacements are requested. Production surface lighting retains its original direction, while the retained sky keeps its separate photographed sun.
- Kept the latest sourced SFX, existing licensed music, unchanged original voice, hidden-tab audio mute and settings accessibility fixes. The owner asked for a visual rollback, so this does not restore the rejected synthesized audio.
- Removed the unused photographic runtime modules and their feature-specific tests. Source assets, concepts, rejected passes, provenance and Git history remain preserved. Unused public source derivatives are not loaded by the game.
- Gameplay rules, bots, weapons, profiles, ghosts and save data are preserved. The optional wider outer salt runoff from checkpoint 2 is reverted with the visual terrain. No new handling experiment or progression system is included.

## Recommended work, in order

These are proposed next tasks, not features implemented by this rollback. Start with **handling, one well-authored circuit, and fair combat**. The game already has eight-pod Battle, weapons, ghosts, Daily courses and a Cup; the opportunity is to make those systems satisfying and dependable.

| Priority | Work to deliver | Why it matters now | Acceptance goal |
| --- | --- | --- | --- |
| **1. Satisfying handling** | Tune braking, drift exit, hover damping and landing transitions together on a compact test course. Preserve tangential momentum on shallow contacts. | The last slope-following experiment caused excess flight and accumulated landing damage; current suspension retains the released tune. | Ten clean laps across the three authored courses, no unexplained launches on ordinary ground, predictable controller braking/drift exit. Version physics and records when behavior changes. |
| **2. Memorable tracks and stronger stylized composition** | Polish one circuit with long acceleration sections, readable banked sweepers, a technical canyon, a risky shortcut and a recovery straight. Frame turns with strong landmarks and a restrained palette under the retained sky; reduce competing props. | Existing canyon/fork/launch transitions and sightlines remain uneven. More random track variations will not fix the core lap. | New players finish without route confusion; bends reveal exits before braking points; one shortcut has a measurable reward and clear risk. Judge actual race screenshots at speed. |
| **3. Fair combat and smarter rivals** | Give shots terrain/scenery occlusion and nearest swept-hit resolution. Replace periodic AI shielding/attack windows with threat-aware reactions and deliberate attack spacing. Protect returning racers from unavoidable repeat wrecks. | Heat Lance currently checks racers without world geometry and returns the first intersected roster entry; AI combat uses periodic windows. | No shots through canyon walls, deterministic nearest hits, readable defence opportunities and fewer consecutive recoveries. Improve existing weapons before adding more types. |
| **4. Distinct pods, then a larger fleet** | Make the four current pods a balanced racer, agile specialist, heavy bruiser and fast heat-sensitive machine. Pair them with different sourced engine identities; admit two additional fully finished models at a time. | Current appearances share the same pod handling; only four of 26 preserved vehicle families are registered. | Players distinguish handling without seeing the model; each pod has a competitive track type. New models require fitted drivers, LODs, source credits and actual race validation. |
| **5. Replayability from mastery** | Calibrate medals per course/pod, give Daily runs meaningful rewards, add a short cosmetic/rival unlock ladder and turn sector losses into immediate retry/practice choices. | Ghosts, records, Daily and Cup already exist. Daily medal thresholds are fixed despite varying generated tracks, and the profile has no unlock ladder. | Three understandable goals for the first hour; bronze/silver/gold difficulty matches measured laps; the results screen gives a clear reason to race again. |
| **6. Clearer feedback and better sound** | Add a short visual combat lesson; communicate ready/fired/blocked states through icons and restrained animation. Audition sourced engines, impacts and pass-bys in complete races; improve spatial placement and ducking. | Flight School teaches driving, but not combat. The current SFX bank is compact and shares player propulsion across pods. | A new player successfully uses shield and mine without a manual; important cues remain clear on laptop speakers and headphones. No generated audio; original voice unchanged. |
| **7. Reliable performance and input** | Establish quality presets from GPU memory and frame-time evidence. Test physical touch driving, controllers/dead zones/reconnect, a full Cup and repeated garage returns. | Existing evidence is chiefly M4 desktop and responsive browser automation. The retained 4K HDR remains a material memory cost. | Sustained 40–60 FPS on named target devices for 20 minutes, with all hitches and resource growth reported; no lost controls or session degradation. |
| **8. Dependable private multiplayer** | Test real two-network latency/loss/disconnect/reconnect/rematch and send selected pod appearances through the protocol. Defer ranked leaderboards until competitive validation is authoritative. | Four-person PeerJS rooms exist, but remote appearance selection and real network acceptance remain incomplete. | Playable races at 100 ms latency / 2% loss; matching selected pods and results for every player; reliable rematches and reconnect handling. |
