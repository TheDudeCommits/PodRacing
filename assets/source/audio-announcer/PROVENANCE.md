# Thrustline announcer sources

Original lines written for Thrustline, generated 2026-09-26 with Higgsfield
text-to-speech (`text2speech_v2`, ElevenLabs engine, preset voice "Knox",
`195e386a-cb61-5c1b-a53b-0e2f0669c408`). The owner approved generated,
on-brand audio for the overhaul. These MP3 files are the unmodified
downloads; `runtime-files.json` records the ffmpeg chain and the SHA-256 of
each shipped Ogg file in `public/audio/announcer/`.
