# Ivory cleanup — JSON value guard correction

The bound V1 payload compared its in-memory reconstruction report directly with the saved JSON proof. `rebuild_owned_mesh()` returned `originalAttributes` and `derivedAttributes` as lists of Python tuples; JSON deserialization returned the same rows as lists of lists. Python therefore reported inequality even when every scalar value matched. This was a preparation bug in the report comparison, not evidence of changed normals or geometry.

The [actual reporting-only retry](02a-cleanup-reporting-only-executed-receipt.json) confirmed the failure at that comparison. The unchanged deep copy passed. Cleanup remained **FAIL**, newly owned IDs were rolled back, all 156 preexisting scenes and 12 guarded ID sets were preserved, both original/source-copy scenes and raw normals were preserved, and the original context was restored. The first failed tool call suppressed the printed receipt because the terminal assertion raised; its original payload and failure remain preserved.

Root's [immutable V2 payload](02b-cleanup-json-value-guard-prepared-v2.py) compares `json.loads(json.dumps(reconstruction, allow_nan=False))` with the same actual proof and records the reconstruction before asserting. This normalizes only Python's tuple/list representation. It retains exact scalar values, all attribute rows, normal hashes, measured differences, geometry/UV/edge signatures, counts, acceptance fields and rollback guards. It adds no numerical tolerance and does not relabel the failed attempt. The terminal rethrow is omitted so guarded failure receipts can be returned; `cleanupPassed` remains the acceptance field.

V2 prepared payload: 136,269 UTF8 bytes; SHA256 `beee618bfeef95c1147cf326a360c624545f4ae28d860d4b8e6926ea64457e99`.

The separate [actual corrected V2 receipt](02b-cleanup-json-value-guard-executed-v2-receipt.json), SHA256 `72f9efa252dcb233d7b95b484a8c9d766d42269bd7b250f59a8ec9040301c4e3`, subsequently records **cleanup PASS**: 43,556 triangles, 55 objects, 51 meshes and 51 materials. It preserves all 156 preexisting scenes, both original/source-copy scenes and their raw normals, and the original context; only the owned derivative IDs are added. The derivative reproduces the accepted own Ivory normal-encoding result: 228 of 14,484 retained vectors differ, maximum 0.03295848962224701 degrees. Those derivative normal vectors are not claimed exact. Neutral comparison and later art acceptance remain separate.
