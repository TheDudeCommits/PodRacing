# Teemto open-cockpit authoring study, round 31

This directory stages a separately named derivative of the existing V4C racer. It does not replace the imported source, any previous derivative, or a public/runtime asset. All original engine and driver geometry, UVs, materials, and anchors are to remain unchanged in the candidate. Only the upper cockpit hull and an explicitly authored opening surround are in scope.

The imported-source GLB records `Cabina` as opaque: no `alphaMode`, no transmission extension, and no reduced base-color alpha. `Rayos`, the original electrical VFX material, is the only source material with `BLEND`. The current V4C `Inkstorm Teemto Cabina` is likewise opaque. The material-study script did rebuild an opaque hull material, replacing the source's normal/ORM/emissive setup; the available source does not establish that a glass material became opaque. The observed side inspection shows an actual enclosed roof above the existing circular side entrance.

The earlier source diagnosis in `../pilot-visibility-round30` found 199/199 sampled driver points hidden by Cabina from the current chase eye. This directory must record the particular triangles/components causing that blockage before selecting an opening. A new open-cockpit silhouette requires finished physical edge trim, an intentional rear coaming, and no dangling former roof hardware. It cannot be represented as a preserved original canopy or as a material-only restoration.

The imported source was acquired from Rafael Fernández Calvo (`rafarelo`), [Teemto Pagalies' Podracer](https://sketchfab.com/3d-models/teemto-pagalies-podracer-4eff45899ada40bb920c5c744663db90), reported [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) in the existing acquisition receipt. Changes for this named derivative: Inkstorm materials and original seated driver inherited from V4C; a separately authored open roof and cockpit surround. The saved imported-source GLB is a connector-normalized export; the acquisition connector did not retain the raw vendor archive.

The finished source-only candidate is `teemto-open-cockpit-round31-candidate.glb`, SHA256 `e7fe0097061d6af30a73538e10608ed8956c6565c3c9fd1fe745d8bf521c03b0`, 7,707,484 bytes. Its upper cockpit hull is physically opened at game height 2.78, with a beveled graphite structural coaming, bone crown, and capped forward/rear mounting decks. Former overhead fittings in this section are removed with the upper hull. This is a deliberately altered open-roadster silhouette; the original enclosed V4C remains available unchanged.

The material diagnosis was confirmed against current source hashes. The original imported source is still `b7e2cc046fd392659886b1af88bdda1117037009351493f69dccdf78c4c53836`; source/public V4C are still `f3eb56a54b7dbb8f4a26263fb26f1f88b188db6bcc409910a3561ae939f1eef1`. `package-candidate.py` copies the entire original 6,763,760-byte BIN chunk verbatim, appends the authored replacement hull and trim geometry, and omits only the unused old cockpit mesh definition from the final JSON. Engine/pilot mesh definitions, accessors, textures, UVs, normals, tangents, existing names, transforms, and hierarchy edges are preserved. No source textures are regenerated.

`validation-receipt.json` verifies 57,234 triangles, both by scene references and all mesh definitions, and 5 body + 6 pilot = 11 opaque draws. This stays within the existing 60,000-triangle, 6-body/6-pilot/12-total-draw limits. Graphite coaming and both deck caps share one primitive. All candidate meshes are referenced; no alpha material is introduced.

`baseline-geometry-diagnosis.json` and `candidate-geometry-diagnosis.json` use the same fixed source chase eye. Unblocked pilot samples increased from 0/199 to 151/199: helmet 56/56, upper body 81/87, lower body 14/56. These are sparse body-occlusion samples, not visible pixels or a percentage of rendered pilot area. The original hit points were on the rear opaque Cabina at game z -6.28 to -6.95 and y 2.63 to 3.56. The new rim/caps correctly continue to occlude some seated lower-body samples.

Four final 1200x800 PNGs inspect the exact packaged candidate: `side`, `chase-eye-cockpit-inspection`, `front-quarter`, and `beauty`. The chase inspection preserves the eye position but aims and zooms toward the cockpit; it is explicitly not a screenshot of the current race-camera composition. The visible helmet and upper torso in these asset renders still require actual in-world race captures and an independent visual critic before acceptance. Runtime-loader admission and frame time also remain root-task checks.

Authoring used Blender MCP only after the root's explicit benchmark release. Each action restored the original `Cruise — Going Merry source 4b2cb678` scene, `ViewLayer`, active `Sketchfab_model.001`, and the exact 15 selected objects. All original scene and collection memberships were checked exactly inside Blender, with only compact receipts returned. Candidate authoring/review scenes are isolated; no shared `.blend` was saved. Original source and V4C files were hash-checked again after the last render. No browser, public asset, or runtime file was changed by this task.

The first missing-deck draft and the later 13-draw candidate are retained in `draft-before-nose-deck` and `draft-before-consolidation` for history. They are not the handoff asset. The final scripts reproduce the coaming, both caps, and graphite consolidation in one authoring pass; the two small follow-up scripts record the actual refinement sequence.
