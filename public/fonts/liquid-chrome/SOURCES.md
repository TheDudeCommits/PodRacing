# Liquid Chrome home typography

The owner selected **A — Orbitron** on 2026-09-22, after reviewing the real-font
comparison. The home menu uses Orbitron at weight 700 for its headings and main
buttons; small utility labels retain the existing Chakra Petch face.

`Orbitron-Variable.ttf` is the unmodified official Google Fonts
`Orbitron[wght].ttf`, downloaded for Round 51, now moved here so the home menu and
comparison page share one cached font resource. Size: 38,576 bytes. Weight range:
400–900. Designer: Matt McInerney. SIL Open Font License: `Orbitron-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/orbitron.
Original metadata/description: `public/style-lab/fonts/orbitron/` in the repository.
The root HTML preloads this self-hosted font; no external font request is required.
