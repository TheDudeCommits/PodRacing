# V18 HUD hierarchy — source frozen, native visual acceptance pending

The reference uses large filled amber stencil numbers on one shallow teal glass. V17 source already fills its numerals, but the amber fill blends with sunlit sky while four-sided dark shadows remain conspicuous. V18 uses 40px Saira stencil readings, no outline shadow, and a single shaped translucent teal timing glass connected to the existing original rail. It preserves the actual lap/total, clock, position/count, target and split values. Narrow typography remains separately sized rather than scaling the entire UI.

The speed SVG is extended into one original C-shaped instrument surrounding three aligned rows: BOOST, HEAT and DAMAGE. Each row keeps its real label, actual percentage and bound fill. A small shaped translucent tray supplies contrast beneath those rows; the overall 244x264 wrapper remains transparent and keeps its original anchors. The redline core-heat channel stays separate on the dial's upper lip. No HULL reinterpretation or generated concept values are introduced.

The inherited base telemetry width:100%!important previously outranked the later horizontal width variable. V18 explicitly binds horizontal heat/damage fills to their existing --pod-meter-value with the required specificity/priority. updateMeter, all values and thresholds remain untouched. Native 0/partial/full bar evidence is required; the CSS syntax/model tests do not prove rendered bar geometry.

Ability cards become open readiness rings with larger original glyphs, actual E/Q/F keys, unchanged readiness-angle updates, weapon name/status accessibility/title, shield-active indication and mine ammo. Route remains a real button with a 44px hit target, embedded in the desktop timing glass and positioned below it on narrow screens. The brief launch result keeps its actual full outcome/detail in a shallower strip. OVER-REV in the V17 image is a launch-result message, not a fabricated replacement for galactic alerts.

Only broadcastStyles.ts and one decorative speed SVG in RaceHud.ts changed. RaceHud's methods and every data-hud selector are byte-identical to V17. The threat layout/grouping/direction/urgency, danger prioritization, launch lifecycle, wreck/recovery/matte handling, gameplay bindings and reduced-motion behavior are unchanged. Build, Map and Garage styles are not edited. The generated target16 image informs composition only and is not native evidence or a replacement for the original critic reference.
