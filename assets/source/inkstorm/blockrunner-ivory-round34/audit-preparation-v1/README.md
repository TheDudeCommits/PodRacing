# Ivory read-only audit — prepared, not executed

Use `ivory-read-only-audit-prepared-v1.py` as one Blender MCP payload. It is **69,118 UTF-8 bytes**, below the 200,000-byte limit. This preparation did not call Blender, a browser or the network, and did not change runtime/public/dist/tests/harness files. Fleet counts remain four families / 22 pending; this only prepares the fifth family.

The external preparer verifies Ivory's existing GLB SHA-256 `2ed231e15b8bbab3f7b7028b73e8b6f442d532c9bc4d1fc0a2f5c40aeda49576`, 2,868,492 bytes, 55 nodes, 51 mesh occurrences/materials, 48,384 triangles and no images. It creates Ivory-owned exact hierarchy references and per-mesh bounds/count/material and local triangle-corner stream references. No Colour expected FNV values, offsets, normal arrays, face IDs or role masks enter the payload. The reused Colour helpers supply algorithms only.

The payload snapshots the actual current window scene, layer, mode, active object and complete selection, plus every current scene's membership/settings and every collection's membership. It does not assume a current scene count or overwrite the original selection with a hardcoded 15-object list. It selects the exact existing Ivory scene, checks its own hierarchy and counts, and emits fresh Ivory structural, UV/material, triangulation and corner-normal FNV signatures.

Original source meshes are never triangulated or edited. The only mesh evaluation uses `evaluated_get`, `to_mesh`, `calc_loop_triangles` on temporary evaluated data, and `to_mesh_clear` in `finally`. The payload has no creation, import, file I/O, render, save, cleanup or mask operation. Its only context writes select the audit scene/layer and restore the exact original context in `finally`; selection/active setters are used only if restoration requires them. All persistent datablock sets, scene settings/memberships, collection memberships and original source signatures are checked again before returning.

The bounded GLB-to-live bridge checks ordered local position, normal and UV corner streams at six decimal places against **Ivory's own GLB**, after the exporter coordinate/UV basis conversion. It checks evaluated topology against the original live mesh, and emits compact triangle-to-polygon/corner runs only when every stream matches. Reordering, rounding mismatch or over 1,024 mapping runs for a mesh leaves that bridge `UNRESOLVED`; no nearest-surface scan or assumed face identity follows. Even a match is declared-precision, non-cryptographic evidence, not byte equality or permission to assign masks. The 9,656-triangle container remains unassigned because it also contains 1,400 body triangles.

`prepared-validation.json` records the exact payload/source hashes and static checks. AST parsing and import/forbidden-call checks passed. **Live source/context preservation and the bridge have not been executed or verified.** Parent owns any subsequent MCP execution and receipt capture between `IVORY_AUDIT_RECEIPT_BEGIN` / `IVORY_AUDIT_RECEIPT_END`.
