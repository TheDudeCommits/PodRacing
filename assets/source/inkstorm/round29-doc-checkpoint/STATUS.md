## Reproduce

Run npm run verify. After build, scripts/inkstorm-gauntlet.mjs captures seven staged sections and a short real-input run. scripts/inkstorm-performance.mjs measures seven separately staged section starts followed by live input: 1.5 seconds warmup and six measured seconds each.

INKSTORM_QUALITY=0 fixes highest quality / DPR 2. Level 4 fixes DPR 1.5. Omitting the variable uses normal adaptive quality. INKSTORM_OUTPUT chooses an evidence directory. Run benchmarks alone. Harnesses close Chrome and preview servers in finally.

The section harness is not continuous full-lap or GPU timer-query evidence. Run `npx --yes tsx scripts/competitive-flow.ts --performance --output=output/playwright/full-race-performance-art-final` for continuous ordinary-race cadence. Its independent performance gate rejects missing/truncated/nonfinite samples, mean cadence below 40 Hz or p95 intervals above 25 ms. Ordinary gameplay acceptance is also required.

Multiplayer and procedural regression commands remain `node scripts/multiplayer.mjs` and `node scripts/procedural-courses.mjs`. `node scripts/inkstorm-asset-fallback.mjs` injects one failed scenery request and tests real fallback UI driving. Browser harnesses always close owned browsers and preview servers.
