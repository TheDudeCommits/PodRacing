# Foundry receiver finish — independent implementation review

8 September 2026. Implementation-aware static QA of `foundry-finish-v1.patch` (SHA-256 `83212fbde6bb174579d55475634814492b160df58645df06d65b87b4fb0872cb`). No browser, shader execution, live edit or fresh visual review was performed. Live application was observed during the read-only review.

**No blocking defect found in the current two-family transform and material path.** The following scope limits remain relevant to actual capture and resource checks.

- The two installed GLBs independently match the preparation hashes: pipe bank `7a28b2e2f3ce25b173ed21033cbe0d28e7341197407b5e86d2400848dba8d946`; service gantry `55d694f8406d9a2ff819ba7d262d86e30f0bc8bafd543699a8ceff83da2380b4`. Each has one mesh/node, no node transform, and one primitive. Loader matrix baking therefore leaves the measured source coordinates unchanged. Six lamp centers/half-widths match the twelve recorded strip-end clusters.
- Existing placement composes translation, Y rotation and positive axis scales. Transform-column lengths therefore recover the actual world metric. Scaling displacement and inverse-scaling the local normal before their dot product is correct in this shared rotated basis, including current nonuniform instances. This is not a general shear-capable transform solution; a future parent transform introducing shear would require a full basis calculation. No such transform was found in the inspected current path.
- Distance is bounded away from zero by `.04`, normal scale by `.001`, and the six positive constant ranges avoid division by zero. Facing/cutoff/envelope/contact terms remain within [0,1] for valid source normals; light accumulation is capped at 1. Contact attenuation cannot become negative. The `3.2` light gain can intentionally exceed display-white linear intensity before encoding; captures must reject excessive cyan clipping. No exposed unvalidated strength input was added.
- The receiver response has no local ray/occluder test. Its depth envelope reduces backside reach but cannot guarantee no light through nearby opaque equipment. Inspect that approximation visually; do not describe it as sampled light or AO. Similarly, radial/orientation shell masks are geometric predicates, not semantic face masks: the comment that they never touch railings is only true where retained railing geometry lies outside those predicates.
- Only pipe-bank and non-grid service-gantry construction opts in. Original grid gantry, generic machinery, workshop, stone and foundations retain the same runtime branches. No GLB bytes, geometry, UVs, color attributes, normal data, collision placement, textures, uniforms or material ownership paths are altered by this patch.
- Steady-state expectation is one extra compiled program, not one material per lamp: pipe-bank splits from generic machinery; the existing emission gantry variant is replaced. Shader-source strings change globally during rebuild, so this does not assert unchanged program IDs across the update. Existing material disposal and borrowed shadow clones are unchanged. Actual program counts and context restoration still need measurements.

GPU compilation, overdraw cost, visible receiver bleed, saturation, repeated contact stripes and motion stability remain untested by this review. The preparation CPU receipt is useful evidence of bounded arithmetic, not a renderer or visual pass.
