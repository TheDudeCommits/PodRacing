# Vehicle asset attribution

## Teemto Pagalies' Podracer

`teemto-hero.glb` and `teemto-rival.glb` are adaptations of **Teemto Pagalies' Podracer** by **Rafael Fernández Calvo (rafarelo)**.

- Original model: https://sketchfab.com/3d-models/teemto-pagalies-podracer-4eff45899ada40bb920c5c744663db90
- Creator: https://sketchfab.com/rafarelo
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)** — https://creativecommons.org/licenses/by/4.0/
- Model UID: `4eff45899ada40bb920c5c744663db90`

Changes by the PodRacing project: normalized scale and rest orientation; rigid engine/cockpit grouping; replaced base-color atlases with Inkstorm repaint adaptations made using Codex imagegen; added an original helmeted driver in a static seated pose; optimized mesh/resources and compressed textures to WebP; created a simplified rival variant. The original source import and source texture copies are preserved separately in the project's asset-source records. These adaptations do not imply the original creator's endorsement.

The source metadata, exact license link, image prompts, source-preservation hashes and export receipts are recorded under `assets/source/inkstorm/vehicles/4eff45899ada40bb920c5c744663db90/` in the project repository.

## Sebulba podracer star wars

`sebulba-hero.glb` and `sebulba-rival.glb` are adaptations of **Sebulba podracer star wars** by **Vlad (vladvhm)**.

- Original model: https://sketchfab.com/3d-models/sebulba-podracer-star-wars-f97e3891a6a846ed97379e3cfa5931a0
- Creator: https://sketchfab.com/vladvhm
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)** — https://creativecommons.org/licenses/by/4.0/
- Model UID: `f97e3891a6a846ed97379e3cfa5931a0`

Changes by the PodRacing project: normalized scale and orientation; replaced shell base color with an Inkstorm repaint adaptation made using Codex imagegen; deliberately converted translucent hardware/glazing to an opaque graphic material; added an original helmeted driver in a static seated pose; merged and reduced body geometry; compressed textures to WebP; created a simplified rival variant. Original imported source and source textures are preserved separately. These adaptations do not imply the original creator's endorsement.

Source metadata, license, prompts and export receipts are recorded under `assets/source/inkstorm/vehicles/f97e3891a6a846ed97379e3cfa5931a0/` in the project repository.
