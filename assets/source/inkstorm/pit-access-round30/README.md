## Bounded CPU evidence and caveats

`study.ts` reproduces data using one canonical course generation, raw terrain plus frozen gulf, five frontage rays per bay, 0.1 m contact search, 0.25 m longitudinal bridge probes, 804 perimeter samples per module/district, and exact separating-axis rectangle projections. No full generation scan or test suite was run.

- New entrance footprint minimum road-edge clearance: **16.455 m** across six strips. Module core perimeter minimum: **23.526 m**. Moved district perimeter: **29.981 m**. These are sampling measurements; they do not replace exact final collider/corridor checks.
- Road/10 m shoulder and normal support are preserved by keeping new grade support literally zero within `10+sqrt(2)+4 = 15.414... m` road clearance. Candidate construction ends outside that support. Both gulf byte hashes were rechecked unchanged. No course or runtime source was modified. There is no new field implementation yet, so no claim of a passing field regression suite.
- The first endpoint trial at13.5 m clearance was explicitly declined: unmodifiable native ground intruded into ideal straight ramps by up to0.702 m. Preserved in `rejected-straight-13m-contacts.json`. Final contacts stop at16.5 m and never enter the protected field zone. Existing terrain beyond the contacts is not magically a smooth accessible continuation; small steps or a contour-following pedestrian path may still be needed there without modifying the shoulder.
- Endpoint grades are **necessary geometry targets, not measured finished ramp slopes**. The new field, actual indexed terrain clearance, ramp support, possible terrain humps under the deck and source geometry openings have not been validated. The wide old plateaus must be removed from the composite field; layering a small patch over existing round29 offsets would leave burial/voids.
- Existing pit collision is an elliptical solid envelope, not a walkable interior. Opening physical racer access requires source-scoped collider decomposition and a shared CPU/render support sampler for the constructed ramp/slab. No collision acceptance is claimed for these proposed entrances. Decorative ramps alone are insufficient.

## Small implementation boundary

Prototype pit216 first: it needs the smaller Y changes and exposes all three differentiated tiers. Then compare the unchanged game/diagnostic cameras before regenerating pit215. Root may stage one source export with three named bay primitives (high/LOD) and a narrow entry construction kit. Reuse instanced closed panels; budget added entry/foundation construction at <=1,000 triangles per bay, six bay modules total, with distance LOD. This is a proposed budget, not an exported count. Removing old shared slabs/walks offsets some cost.

Rebuild one combined atlas from ungraded terrain plus gulf; remove old215/216 anchors and use simultaneous slab ceilings for all surviving/new modules. No special previous-pit freeze. Keep existing 1 m R32F four-texel sampler and 1024-dimension/524288-texel cap. Verify coarse indexed mesh at old fixed cameras plus fractional phases before source integration. Decline a placement if its terrain ceiling cannot be met outside the protected road support. Nonflagship seeds retain round29 until their placement is measured.

At root request the study stops here to release CPU/agent capacity. No second option or automatic integration is proposed.
