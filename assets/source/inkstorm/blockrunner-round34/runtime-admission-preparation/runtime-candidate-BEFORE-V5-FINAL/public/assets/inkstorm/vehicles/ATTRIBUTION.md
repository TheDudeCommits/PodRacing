# Vehicle asset attribution

## Teemto Pagalies' Podracer

The preserved `teemto-hero.glb`, `teemto-hero-v4b.glb`, `teemto-hero-v4c.glb`, `teemto-hero-open-v1.glb`, `teemto-hero-open-v2.glb` and `teemto-rival.glb` revisions are adaptations of **Teemto Pagalies' Podracer** by **Rafael Fernández Calvo (rafarelo)**.

- Original model: https://sketchfab.com/3d-models/teemto-pagalies-podracer-4eff45899ada40bb920c5c744663db90
- Creator: https://sketchfab.com/rafarelo
- License: **Creative Commons Attribution 4.0 International (CC BY 4.0)** — https://creativecommons.org/licenses/by/4.0/
- Model UID: `4eff45899ada40bb920c5c744663db90`

Changes by the PodRacing project: normalized scale and rest orientation; rigid engine/cockpit grouping; replaced base-color atlases with Inkstorm repaint adaptations made using Codex imagegen; added an original helmeted driver in a static seated pose; optimized mesh/resources and compressed textures to WebP; created a simplified rival variant. Later hero revisions refine the original static driver clothing, harness and material maps. Open-cockpit revisions reshape the cockpit cowling and add a rim, liner, seams and fasteners while retaining the original engine geometry. The original source import and source texture copies are preserved separately in the project's asset-source records. These adaptations do not imply the original creator's endorsement.

The source metadata, exact license link, image prompts, source-preservation hashes and export receipts are recorded under `assets/source/inkstorm/vehicles/4eff45899ada40bb920c5c744663db90/` in the project repository.

- Original model: https://sketchfab.com/3d-models/none-a6f14ae799ab40d7ac425f043f824ff8

- Model UID: `a6f14ae799ab40d7ac425f043f824ff8`

Changes by the PodRacing project: removed exact overlapping opposing faces; shortened two grips and added two side mounts while retaining the original seated minifigure pilot; authored and baked an Inkstorm paint and roughness treatment; consolidated rigid geometry, normalized scale and orientation, and packaged distinct hero/rival derivatives with resized body and pilot atlases.
