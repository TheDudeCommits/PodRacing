# Contact shading and MRT background correction — round27

The new contact-shading candidate initially produced a dark sky with bright terrain contours. It is rejected in the preserved `output/gauntlet/round27-candidate1/` capture. The subsequent controlled GPU diagnosis identified an existing prepass-clear bug exposed by the new feature: Three's `Color` scene background forces a color clear even with `renderer.autoClear=false`, overwriting both deliberately different MRT attachment clear values.

`scripts/inkstorm-contact-attribution.mjs` serves a disposable diagnostic entry with the actual app exposed through a Vite transform. It does not edit the production entry. Nine actual screenshots and readback receipts are preserved under `output/gauntlet/contact-attribution-round27/`. The first state is the unfixed source; the next temporarily withholds the scene background during prepass only; the last disables contact shading while retaining that correction. Grid, launch and foundry views were captured. Camera near/far at these views was0.35/18000; no depth range was guessed.

At all three sampled launch sky locations, both attachments originally read `[5,3,24,255]`. Decoding this background color as depth created a fictitious surface at roughly354m. With the background withheld, the same samples read normal`[128,128,255,0]` and depth`[255,255,255,0]`, correctly identifying empty sky. The ordinary scene background remained`#281f56` after every sample. All diagnostic browser errors were empty. Actual comparisons remove the sky halo.

The runtime fix in `CelPostPipeline.renderPrepass` saves/withholds the scene background and restores it in `finally`, alongside override material, target and auto-clear state. Two focused regression cases exercise success and a thrown draw. Both pass, and two projection tests verify perspective reconstruction across FOV/view-offset changes. The GPU readback is the separate evidence that those mathematical and lifecycle checks match actual attachment contents.

The contact effect reconstructs view-space positions from existing packed linear depth and samples twelve nearby directions. A world-distance limit rejects unrelated foreground/background contacts. It introduces no new geometry, draw pass, render target or allocation; enabled shading adds a center depth/normal read and twelve neighbor depth reads. No extra reads run when the strength is zero.
